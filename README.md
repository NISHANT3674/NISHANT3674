# 🧪 Sarveswary Pharma Website

A modern, responsive veterinary pharmaceutical website for **Sarveswary Pharma**, built with **Next.js 15**, **TypeScript**, and **MongoDB**. It includes an admin dashboard for managing products, a secure login system, and a clean, mobile-friendly UI.

## 🔗 Live Site

🌐 [sarveswary-pharma.vercel.app](https://sarveswary-pharma.vercel.app)

---

## 🚀 Features

- 💊 Display featured veterinary products
- 🔐 Admin login/logout with secure session management
- 📦 Full product CRUD from admin dashboard
- 🎨 Clean UI with full-page loader and dark/light support
- 📱 Fully responsive across devices
- ⚡ Fast image loading with Next.js optimization

---

## 📁 Tech Stack

- **Frontend:** Next.js 15 (App Router) + TypeScript + Tailwind CSS
- **Backend:** API Routes + MongoDB + Mongoose
- **Auth:** NextAuth.js (credentials provider)
- **Deployment:** Vercel
